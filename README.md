# Gearsetter

[Gearsetter](https://github.com/VeraNala/Gearsetter) 的台服移植版，查詢各職業可換裝的裝備升級。

## 功能

- **裝備升級檢查**：比對目前所有套裝的每個部位與背包/裝備庫存中更好的裝備，逐一列出可升級項目，並附上聊天連結可直接切換到該套裝
- **裝備瀏覽器**：依職業與部位分類瀏覽所有可裝備品項，可篩選「只顯示等級符合的裝備」、「只顯示已擁有的裝備」、「隱藏 NQ 裝備」，並標示每件裝備的取得來源
- **進入軍隊區域自動提示**（可於設定關閉）：進入自軍所屬的軍隊駐紮地時自動列出可升級裝備
- **IPC**：提供 `Gearsetter.GetRecommendationsForGearset`，供其他插件查詢指定套裝的裝備升級建議
- **指令**：`/gup`（列出所有套裝的可升級部位，可加等級參數限定職業當前等級）、`/gbrowser`（開關裝備瀏覽器）
